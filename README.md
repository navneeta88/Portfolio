# Portfolio 🚀

A personal portfolio website built with HTML, CSS, and JavaScript.

🌐 **Live Site:** https://navneeta88.github.io/Portfolio/

---

## 📌 Sections

- **Home** — Introduction with typing animation
- **About** — Brief bio
- **Stats** — Projects, skills, problems solved
- **Skills** — Category cards (Languages, Web, CS Fundamentals, Tools)
- **Experience** — Education & project timeline
- **Projects** — Cards with GitHub & demo links
- **Certifications** — Courses & certificates earned
- **Hackathons** — Events and competitions attended
- **Contact** — Email, GitHub, LinkedIn, LeetCode

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons
- Google Fonts (Syne + DM Sans)

---

## ✨ Features

- Dark / Light mode toggle
- Typing animation
- Scroll reveal animations
- Animated stats counter
- Skill category cards
- Responsive on mobile
- Back to top button
- Cursor glow effect
